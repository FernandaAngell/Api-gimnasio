# 🏋️‍♀️ API Gimnasio

## 📚 Descripción

Este repositorio contiene el desarrollo de una API en Python 🐍 utilizando **FastAPI**, como parte de mi aprendizaje en desarrollo backend.

Se trabajan conceptos fundamentales como:

* Creación de APIs REST
* Autenticación con JWT 🔐
* Manejo de base de datos con SQLAlchemy 🗄️
* Encriptación de contraseñas
* Organización de proyectos por módulos

---

## 📂 Contenido

### 👤 Usuarios

Registro de usuarios, listado y validación de datos.

---

### 🔐 Autenticación

Sistema de login con generación de tokens JWT para acceso seguro.

---

### 🏋️ Rutinas

Gestión de rutinas de entrenamiento según nivel del usuario.

---

### 📈 Progreso

Registro y seguimiento del progreso físico (peso y fechas).
